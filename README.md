# SPANISH-LANGUAGE MUSIC CLASSIFIER - Machine Learning Project

## Project Overview

This project contains Python code for exploring, modelling and evaluating machine learning approaches to enable automatic (Spanish) language detection in audio tracks using non-lyrical metadata.

It includes:

- Data preparation pipelines
- Feature engineering
- Model training and evaluation
- Experiment tracking and evaluation
